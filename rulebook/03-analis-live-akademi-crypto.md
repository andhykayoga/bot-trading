1. **Jual:** "beli setahun sebelum halving, jual setahun setelah halving" ([AC_crypto_4 L420–L435](../materi/mentah/AC_crypto_4.txt#L420-L435)). Di live lain: puncak potensial **±500 hari setelah halving** ([AC_crypto_3 L51–L55](../materi/mentah/AC_crypto_3.txt#L51-L55), [AC_crypto_1 L105–L125](../materi/mentah/AC_crypto_1.txt#L105-L125)).
2. **Saat puncak, tidak menjual semuanya:** sisakan, lalu pindahkan sebagian ke **30% emas dan 30% cash** (*rebalancing*) ([AC_crypto_4 L21–L40](../materi/mentah/AC_crypto_4.txt#L21-L40), [AC_crypto_4 L271–L290](../materi/mentah/AC_crypto_4.txt#L271-L290)).
3. **Setelah turun tajam, jangan "menangkap pisau jatuh"**: tunggu harga konsolidasi berbulan-bulan; kurangi trading di fase ini ([AC_crypto_4 L111–L179](../materi/mentah/AC_crypto_4.txt#L111-L179)).
4. **Area beli** ditentukan dari: high ATH siklus sebelumnya + golden pocket Fibonacci + angka bulat (contoh 50 ribu). Data mentor: koreksi bear market biasanya 70–80% dari puncak ([AC_crypto_4 L141–L220](../materi/mentah/AC_crypto_4.txt#L141-L220)).
5. **Beli bertahap**: contoh 50% di area utama, 30% lagi kalau ada penurunan ±20% lebih dalam ([AC_crypto_4 L221–L255](../materi/mentah/AC_crypto_4.txt#L221-L255), [AC_crypto_5 L1–L50](../materi/mentah/AC_crypto_5.txt#L1-L50)).
6. **Target alokasi setelah membeli:** 70% BTC, 30% cash (atau 20% cash + 10% emas) ([AC_crypto_5 L11–L20](../materi/mentah/AC_crypto_5.txt#L11-L20)).
7. Altcoin hanya **2–5%** portofolio ([AC_crypto_5 L391–L400](../materi/mentah/AC_crypto_5.txt#L391-L400)).

**Belum jelas:**

- "Setahun setelah halving" atau "500 hari setelah halving"? Dua angka ini berbeda ±4–5 bulan → **Q-27**.
- Apakah bot mengelola investasi jangka panjang sama sekali → **Q-29**.

## LIVE-02 · Token baru (TGE): 30% saat listing, 70% di base

| | |
|---|---|
| Sumber | [AC_crypto_1 L460–L951](../materi/mentah/AC_crypto_1.txt#L460-L951) |
| Pasar | K (spot) |
| Status | 🔴 (butuh data valuasi investor yang diinput manual) |

**Aturan yang diucapkan mentor:**

1. **Jangan beli di pre-market**; tunggu token listing di spot ([AC_crypto_1 L480–L490](../materi/mentah/AC_crypto_1.txt#L480-L490)).
2. **Harga lantai (*floor*)** = valuasi investor terakhir ÷ jumlah token maksimum. Contoh: investasi di valuasi $1,5 miliar, *max supply* 1 miliar token → lantai $1,5 ([AC_crypto_1 L491–L530](../materi/mentah/AC_crypto_1.txt#L491-L530), [AC_crypto_1 L855–L880](../materi/mentah/AC_crypto_1.txt#L855-L880)).
3. **Target** dari perkiraan FDV dan pendapatan proyek (contoh $5–10) ([AC_crypto_1 L520–L545](../materi/mentah/AC_crypto_1.txt#L520-L545)).
4. **Masuk 30%** di harga listing ([AC_crypto_1 L641–L650](../materi/mentah/AC_crypto_1.txt#L641-L650)).
5. Pola yang sering terjadi: setelah listing harga turun **50–66%**, lalu membentuk **base**. **Masuk 70%** sisanya di base dekat lantai ([AC_crypto_1 L615–L640](../materi/mentah/AC_crypto_1.txt#L615-L640), [AC_crypto_1 L650–L720](../materi/mentah/AC_crypto_1.txt#L650-L720)).
6. **Cut loss** di bawah lantai (contoh $1,25 untuk lantai $1,5) ([AC_crypto_1 L681–L690](../materi/mentah/AC_crypto_1.txt#L681-L690)).
7. **Base hanya sekali** ("drop–base–up"). Kalau turun lagi membentuk base kedua, ketiga, jangan terus mencicil ([AC_crypto_1 L691–L720](../materi/mentah/AC_crypto_1.txt#L691-L720), [AC_crypto_1 L925–L940](../materi/mentah/AC_crypto_1.txt#L925-L940)).
8. Kalau naik 2×: *moon bag* ([KMS-I2](02-kalimasada-akademi-crypto.md#kms-i2--moon-bag)). TP bertahap sepanjang kenaikan.
9. Alokasi total untuk permainan ini **±5% portofolio** ([AC_crypto_1 L731–L735](../materi/mentah/AC_crypto_1.txt#L731-L735), [AC_crypto_1 L891–L900](../materi/mentah/AC_crypto_1.txt#L891-L900)).

**Kenapa 🔴:** lantai harga butuh data valuasi investor dan *max supply* yang harus dicari dan dimasukkan manual. Bot hanya bisa menjalankan bagian eksekusinya (30/70, cut loss, moon bag) setelah angka itu diisi → **Q-30**.
